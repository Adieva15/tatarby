## О проекте

Человек, который говорит на татарском, не всегда может свободно читать. Незнакомые слова, сложные предложения, нет инструментов для разбора. Приложение помогает читать татарские тексты, адаптирует их под уровень и возраст, разбирает сложные слова и проверяет понимание.

## Возможности

- **Адаптивное чтение** — текст подстраивается под уровень владения языком и возраст.
- **Карточки** — запоминание незнакомых слов в игровом формате.
- **Вопросы** — проверка понимания прочитанного.
- **Сочинение** — пересказ своими словами с проверкой через LLM.
- **Профиль** — уровень, XP, streak, статистика.
- **Достижения** — мотивация через игровые награды.
- **Аналитика** — графики активности и прогресса.
